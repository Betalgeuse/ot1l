# 커스텀 이모지 운영 가이드

이 문서는 새로 다운로드한 커스텀 이모지를 Slack에 등록하고 Townhall에 알릴 때의 기준 절차입니다.

## 불변조건

- Downloads의 원본 파일은 이름 변경, 재압축, 이동, 삭제하지 않습니다.
- 업로드 전에 SHA-256으로 같은 파일을 제거하고 `emoji.list`로 이미 등록된 이름을 확인합니다.
- 이름이 겹치지만 이미지가 다르면 내용을 설명하는 접미사를 붙여 두 자산을 모두 보존합니다.
- Slack이 GIF를 거절하면 임시 폴더의 복사본만 프레임 수·크기·색상을 줄입니다. 애니메이션 여부를 다시 확인하고 원본은 유지합니다.
- 완료 수량은 로컬 업로드 횟수가 아니라 마지막 `emoji.list`에서 확인된 이름 수로 계산합니다.

## 등록 절차

1. 요청된 다운로드 시각 범위의 GIF·PNG·JPG·WEBP를 하위 폴더까지 조사합니다.
2. 파일별 크기, 형식, 이미지 크기와 SHA-256을 기록하고 중복 파일을 제외합니다.
3. 파일명에서 Slack 이름을 정합니다. 의미 없는 번호·접미사는 정리하되 서로 다른 이미지를 같은 이름으로 합치지 않습니다.
4. 현재 `emoji.list`와 대조해 이미 등록된 동일 이름을 건너뜁니다. 이름이 같은 기존 이미지가 다른 파일이면 `_alt`처럼 의미가 분명한 새 이름을 사용합니다.
5. Slack **Customize → Emoji → Add Custom Emoji**에서 등록합니다. 업로드가 중간에 멈추면 로컬 카운터가 아니라 최신 `emoji.list`부터 다시 읽고 남은 파일만 계속합니다.
6. 모든 후보 이름을 `emoji.list`에서 다시 읽어 누락이 0인지 확인합니다.

## Townhall 공지

- 기존 업데이트 공지가 있으면 같은 글을 수정하고, 없으면 Townhall 최상위 글을 한 건 만듭니다.
- 본문은 `커스텀 이모지 N종이 업데이트됐어요. 자유롭게 써보세요.`처럼 짧게 씁니다.
- `아래 이름으로 사용할 수 있어요` 같은 이름 목록은 넣지 않습니다.
- 새 이모지 리액션은 공지 최상위 글에만 추가합니다. Slack의 메시지당 리액션 종류 한도에 닿으면 대표 이모지만 남기고 나머지를 스레드 댓글로 넘기지 않습니다.
- 스레드에는 `다른 포켓몬이나 커스텀 이모지 수요도 있으면 이 스레드에 알려주세요!`라는 댓글만 남깁니다. 이 수요 댓글에는 봇 리액션을 달지 않습니다.

## 완료 검증

1. `emoji.list`에서 요청 자산 전체의 이름이 존재하는지 확인합니다.
2. `conversations.replies`를 GET query parameter로 읽어 공지 본문과 수요 댓글을 확인합니다.
3. 공지 최상위 글의 새 리액션만 확인하고 수요 댓글의 봇 리액션은 0인지 확인합니다.
4. 기존 사람 리액션과 과거 메시지는 변경하지 않았는지 대조합니다.
