# Townhall 이벤트

이 문서는 회원이 이벤트를 열고 시간을 맞추고 참가하는 제품 계약입니다. 운영 반영 여부는 정확한 배포 SHA와 Slack·브라우저 readback으로 별도 확인합니다.

## 이벤트 열기

1. 날짜가 정해졌다면 **일정 정해서 열기**, 아직 정하지 않았다면 **시간 미정 이벤트 열기**를 누릅니다.
2. 바로 주최하기 전 반응을 보고 싶다면 **수요 먼저 확인하기**, 다른 회원이 열어주길 원하면 **누가 좀 열어주세요**를 사용합니다.
3. 주최자 이름은 입력하지 않습니다. 버튼을 누른 Slack 회원을 주최자로 표시하고 참가 확정 1명에 포함합니다.
4. 활동과 장소 또는 접속 방법을 적습니다. 고정 일정은 시작 시와 `00분` 또는 `30분`, 진행 시간을 선택합니다.
5. 시간 미정 이벤트는 주간 달력에서 “이 시간으로 확정되면 참가할 수 있는 시간”을 복수 선택합니다. 주최자가 한 칸을 확정하면 그 칸을 선택한 회원은 자동 참가됩니다.

## 참가와 성사

- **최소 성사 인원**은 모임이 열리는 기준이며 정원이 아닙니다.
- **최대 인원**은 별도 값입니다. 비우면 무제한이고, 차면 이후 신청은 대기자로 기록합니다.
- Slack 리액션은 자유로운 반응이며 참가나 관심 수치의 정본으로 집계하지 않습니다.
- 참가자와 확정 인원은 이벤트 카드와 스레드에서 확인합니다.
- 모집 마감에 최소 인원이 부족하면 취소 유예로 바뀌고, 유예가 끝날 때까지 미달이면 자동 취소·보관합니다.
- 이벤트 시간이 지난 뒤에만 주최자를 멘션해 후기 등록을 요청합니다.

## 수요와 여러 주최자

수요 카드의 스레드에서 가능한 시간·장소와 다음 활동 아이디어를 모읍니다. **내가 주최할래요!**는 수요 내용을 채운 시간 미정 이벤트를 열고, 이벤트가 생긴 뒤에도 **나도 주최하기**로 별도 이벤트를 만들 수 있습니다. 제안자는 수요를 수정하거나 마감할 수 있습니다.

## 수정

주최자는 Slack의 **이벤트 수정**에서 활동, 장소, 최소 성사 인원, 최대 인원과 확정 일정을 바꿀 수 있습니다. 시간 후보 범위나 정기 회차를 크게 바꾸면 웹 시간표를 다시 설정하고 최종 시간을 재확정합니다.

## 시스템 경계

- Slack 카드, 회원 상태, 이벤트 lifecycle과 DB mutation은 Core Worker `otl1-onething-garden`이 담당합니다.
- 공개 시간표 UI와 이벤트 전용 Core 프록시는 `otl1-time`이 담당합니다.
- Open Worker에는 Slack token, DB URL, SSH key를 두지 않습니다. 이벤트 전용 HMAC과 Core service binding만 사용합니다.
- Open/Core 분류의 실행 원본은 `automation/runner/change-policy.mjs`입니다. 경로가 섞이면 Core로 분류합니다.

운영 점검과 비밀 이름은 [운영 가이드](OPERATIONS.md), 로컬 검사와 배포 절차는 [개발 가이드](DEVELOPMENT.md)를 따릅니다.
