# 영어 허들 AI 회화 구상 — 보류

상태: **보류, 미구현·미배포**. 2026-10-11 사용자 요청으로 문서만 보존합니다. 재개 요청 전에는 operator 상주, 음성 수집, 공급자 연결, 예약 작업을 시작하지 않습니다.

## 목적과 후보 경험

`chapter-english-beta`에서 별도 앱으로 이동하지 않고 5~10분 외국어 대화를 연습합니다. 오늘 원띵이나 읽은 책을 본인이 선택해 대화 주제로 활용할 수 있습니다. 사람끼리 대화할 때는 AI를 완전히 중지할 수 있어야 합니다.

검토한 후보는 기존 operator 계정을 실제 허들 참가자로 접속하고, 전용 실행환경의 가상 오디오 장치를 통해 음성 인식 → 대화 모델 → 음성 합성을 연결하는 방식입니다. 아직 실제 양방향 음성, 지연, 중단, 복구를 검증하지 않았습니다. Slack의 공식 지원 기능으로 표현하지 않습니다.

## 재개 시 지켜야 할 경계

- QA용 operator와 상시 회화 실행환경은 분리합니다. 일반 작업용 브라우저나 주변 마이크를 수집하지 않습니다.
- AI임을 명시하고 참가자의 음성 처리 동의를 확인하기 전에는 외부 공급자로 음성을 보내지 않습니다. 신규 참가자의 동의를 확인할 수 없으면 처리를 중지합니다.
- 녹음·전사 저장은 기본 꺼짐입니다. 공급자의 보존 정책, 로그·추적에 포함되는 내용도 확인합니다.
- 대화 에이전트에 Slack 관리, PO 승인, PR 병합, 배포 또는 운영 자격증명을 주지 않습니다.
- 원띵 완료를 자동 판정하지 않습니다. 교정·표현 저장·다음 주제 기억은 선택 사항입니다.
- 초기 실험은 동의한 한 사람과 AI만 사용합니다. 다자간 화자 식별은 별도 검증 대상입니다.
- 음성 되먹임, 끼어들기, 네트워크 단절, 재로그인, 가상 장치 변경, 퇴장 후 처리·과금 종료를 시험합니다.

## 대안과 근거

- 사람끼리 대화한다면 채널의 고정 허들 링크만으로 시작할 수 있습니다. 마지막 사람이 나가면 허들이 종료됩니다.
- 공식 Calls API는 외부 통화와 Slack 표시를 연결하며, Slack 허들 음성을 봇에 제공하는 API가 아닙니다.
- operator 음성 중계의 안정성 또는 정책 적합성이 확보되지 않으면 별도 웹 음성방을 검토합니다. 자동으로 이 대안에 착수하지 않습니다.
