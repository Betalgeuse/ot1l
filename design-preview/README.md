# OT1L 디자인 시안

기존 홈페이지 문구를 활용한 흑백 중심의 검토용 정적 시안입니다.
운영 홈페이지 및 Slack 가입·데이터 연동 코드는 변경하지 않습니다.

## 미리보기

이 저장소 루트에서 다음 명령을 실행한 뒤 http://127.0.0.1:8765 를 엽니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory design-preview
```

별도 설치나 빌드가 필요 없으며 `index.html`을 브라우저에서 직접 열어도 됩니다.
이 로컬 주소는 다른 사람에게 공유할 수 있는 공개 배포 주소가 아닙니다.

## 디자인 기준

- 흑백 대비와 여백을 중심으로 한 단순한 구성.
- 중앙 정렬한 검정 표지와 고정 헤더, 가로 페이지 전환 구성. 하단 내비게이션은 페이지 번호·화살표 없이 가운데 네 단계(선 + 이름)만 두고, 현재 페이지는 빨간 선으로 표시합니다. 단계 클릭, 방향키, 휠, 스와이프로 이동합니다.
- 습관(루틴) 안내는 가운데 ‘습관’을 번호 1·2·3을 붙인 SET → DO → REVIEW가 감싸는 얇은 원형 고리로 표시하고, 작은 빨간 점이 고리를 따라 천천히 돕니다(동작 줄이기 설정 시 정지). 각 단계를 누르면 한 개의 네이티브 dialog 뷰어가 해당 단계부터 열리고, SET·DO·REVIEW 상세를 가로로 넘깁니다. 위쪽의 1 SET — 2 DO — 3 REVIEW 순서 표시는 넘겨도 항상 고정되며 현재 단계는 검정으로 반전됩니다(순서 표시 클릭, ←·→ 키, 스와이프로 이동). × 버튼 또는 Escape로 닫습니다.
- 예시는 회색 상자와 ‘예시’ 표시로 설명과 구분합니다(상세 뷰어와 ‘나란히’ 페이지).
- ‘나란히’ 페이지는 사업가·직장인·학자의 ONE THING을 평행한 세 줄로 표시합니다. 각 줄의 빨간 점이 서로 다른 속도로 같은 방향을 향해 움직여, 각자의 길을 걸으며 함께 성장한다는 뜻을 나타냅니다. 점이 선 끝에 도달(완료)하면 슬랙식 이모지 반응(👏·🔥·🎉 등과 개수)이 차례로 붙어 서로의 응원을 보여줍니다. 동작 줄이기 설정 시 점은 서로 다른 위치에 정지하고, 직장인 줄만 완료 상태와 반응을 보여줍니다.
- 누를 수 있는 요소(습관 단계, 표지 버튼, 상세 뷰어의 순서 표시·닫기)는 마우스를 올리거나 키보드로 선택하면 검정 바탕·흰 글씨로 반전합니다. 검정 표지와 어두운 헤더·페이저에서는 흰 바탕·검정 글씨입니다.
- ONE과 숫자 1은 빨간색, ‘가장 중요한 업무 하나’는 밑줄로 강조.
- 목표 설정, 실행, 회고, 커뮤니티, 참여 안내를 순서대로 표시.
- 기존 홈페이지의 가상 대화와 목표 예시를 유지.

현재 디자인 검토 중이며 운영 반영 전 초대·문의 기능 연결과 브라우저 검증이 필요합니다.

## 첨부 시안 검토

2026-10-08 전달받은 HTML을 그대로 반영했습니다. 외부 통신·외부 스크립트·폼·브라우저 저장소 사용은 없으며, 페이지 번호 출력은 내부 숫자만 사용합니다. 정적 코드 검토에서 비밀키나 토큰은 발견되지 않았습니다.

페이지 전환은 JavaScript에 의존합니다. 방향키·스페이스 키의 기본 동작을 바꾸므로 키보드 탐색, 작은 화면의 스크롤, 포커스 이동은 실제 브라우저에서 추가 검토해야 합니다.
